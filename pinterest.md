# Privacy Policy

Last updated: [Current Date]

## Overview
This privacy policy describes how our Pinterest API integration application ("the App") collects, uses, and handles your information.

## Information Collection
The App only processes the following information necessary for Pinterest API integration:
- Pinterest board IDs
- Image URLs for pin creation
- Pin titles and descriptions
- Authentication tokens

We do not store any personal information or Pinterest user data. All data is processed temporarily during API calls and is not permanently stored.

## Data Usage
The information processed by the App is used solely for:
- Creating pins on specified Pinterest boards
- Authenticating with the Pinterest API
- Maintaining necessary API functionality

## Data Sharing
We do not share, sell, or distribute any data with third parties. All operations are conducted directly between our application and Pinterest's API.

## Data Security
We implement appropriate security measures to protect your authentication tokens and any temporary data processed by our application.

We may update this privacy policy from time to time. Any changes will be posted on this page.
