Privacy Policy

Last updated: December 1, 2024

Overview

This privacy policy describes how PageManager ("we", "our", or "us") collects and uses information through our Facebook application.

Information Collection

Our app only accesses Facebook pages owned and managed by the app administrator. We collect and process the following information:

  • Page access tokens for administrator-owned Facebook pages
  • Basic page information required for posting updates

Use of Information

The information we collect is used solely for:

  • Authenticating with the Facebook API
  • Posting updates to administrator-owned Facebook pages
  • Managing scheduled content on administrator-owned pages

Data Sharing and Disclosure

We do not share, sell, rent, or trade any information with third parties. The app only interacts with Facebook's APIs to post content to pages owned by the administrator.

Data Storage

  • We store only the minimum required authentication tokens needed for the app to function
  • All data is stored securely and used only for authorized posting to Facebook pages
  • Data is retained only as long as necessary for the app to function

Third-Party Services

Our app uses the following third-party services:

  • Facebook Graph API for posting content
  • Cloudflare Workers for hosting our application logic

User Rights

As this app is for personal/administrative use only, all data control is maintained by the app administrator.

Security

We implement appropriate technical and organizational measures to protect the information we collect and store.

Changes to This Policy

We may update this privacy policy from time to time. We will notify users of any material changes by posting the new privacy policy on this page.
